# 基于AOP实现日志管理

## 一、概述

### 1.1 什么是日志管理？
日志管理是指记录系统运行过程中的重要操作和事件，主要分为两类：
- **技术日志**：记录代码执行细节、异常堆栈、性能指标（使用Logback/SLF4J）
- **业务日志**：记录用户操作行为、数据变更、审计追溯（使用AOP实现）

### 1.2 为什么需要AOP实现业务日志？
传统方式需要在每个方法中手动记录日志：
```java
public void deleteUser(Long userId) {
    log.info("开始删除用户，userId={}", userId);
    userMapper.deleteById(userId);
    
    // 手动保存操作日志到数据库
    OperationLog log = new OperationLog();
    log.setUsername(getCurrentUser());
    log.setOperation("删除用户");
    log.setParams("userId=" + userId);
    logMapper.insert(log);
}
```

**问题**：
- ❌ 代码重复，每个方法都要写一遍
- ❌ 业务逻辑和日志记录耦合
- ❌ 容易遗漏，某些方法忘记记录

**使用AOP后**：
```java
@OperationLog(module = "用户管理", operation = "删除用户")
public void deleteUser(Long userId) {
    userMapper.deleteById(userId);
}
```

**优势**：
- ✅ 一个注解搞定，代码简洁
- ✅ 业务逻辑和日志记录解耦
- ✅ 统一管理，不会遗漏

### 1.3 AOP日志与Logback的区别

| 维度 | Logback技术日志 | AOP业务日志 |
|------|----------------|------------|
| **作用** | 记录代码执行信息、异常堆栈 | 记录用户操作行为、审计追溯 |
| **使用** | `log.info()` / `log.error()` | `@OperationLog` 注解 |
| **存储** | 文件、控制台 | 数据库、ES |
| **目标用户** | 开发人员排查问题 | 运营/审计人员查看操作记录 |
| **内容示例** | `查询参数: {userId=123}` | `张三在2025-12-01删除了用户123` |

**结论**：两者互补，需要同时使用。

### 4.1 自定义注解

```java
package com.zyh.easyapplyresume.annotation;

import java.lang.annotation.*;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface OperationLog {
    
    /**
     * 功能模块
     */
    String module();
    
    /**
     * 操作类型
     */
    String operation();
    
    /**
     * 是否记录请求参数
     */
    boolean recordParams() default true;
    
    /**
     * 是否记录返回结果
     */
    boolean recordResult() default false;
}
```

### 4.4 AOP切面（核心）
**文件位置**：`aspect/OperationLogAspect.java`

```java
package com.zyh.easyapplyresume.aspect;

import cn.hutool.core.util.StrUtil;
import cn.hutool.json.JSONUtil;
import com.zyh.easyapplyresume.annotation.OperationLog;
import com.zyh.easyapplyresume.mapper.mysql.OperationLogMapper;
import com.zyh.easyapplyresume.model.pojo.OperationLogEntity;
import com.zyh.easyapplyresume.security.SecurityUser;
import jakarta.servlet.http.HttpServletRequest;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.reflect.MethodSignature;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.context.request.RequestContextHolder;
import org.springframework.web.context.request.ServletRequestAttributes;

import java.time.LocalDateTime;
import java.util.Arrays;
import java.util.stream.Collectors;

@Aspect
@Component
@RequiredArgsConstructor
@Slf4j
public class OperationLogAspect {
    
    private final OperationLogMapper operationLogMapper;
    
    @Around("@annotation(operationLog)")
    public Object around(ProceedingJoinPoint joinPoint, OperationLog operationLog) throws Throwable {
        OperationLogEntity logEntity = new OperationLogEntity();
        
        long startTime = System.currentTimeMillis();
        Object result = null;
        String status = "SUCCESS";
        String errorMsg = null;
        
        try {
            logEntity.setModule(operationLog.module());
            logEntity.setOperation(operationLog.operation());
            logEntity.setMethodName(joinPoint.getSignature().toShortString());
            
            ServletRequestAttributes attributes = (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
            if (attributes != null) {
                HttpServletRequest request = attributes.getRequest();
                logEntity.setRequestMethod(request.getMethod());
                logEntity.setIpAddress(getIpAddress(request));
                logEntity.setUserAgent(request.getHeader("User-Agent"));
            }
            
            Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
            if (authentication != null && authentication.getPrincipal() instanceof SecurityUser) {
                SecurityUser securityUser = (SecurityUser) authentication.getPrincipal();
                logEntity.setUsername(securityUser.getUsername());
                logEntity.setUserType(securityUser.getUserType());
            } else {
                logEntity.setUsername("匿名用户");
                logEntity.setUserType("unknown");
            }
            
            if (operationLog.recordParams()) {
                Object[] args = joinPoint.getArgs();
                String params = Arrays.stream(args)
                        .map(arg -> {
                            if (arg instanceof HttpServletRequest || arg instanceof SecurityUser) {
                                return null;
                            }
                            return JSONUtil.toJsonStr(arg);
                        })
                        .filter(StrUtil::isNotBlank)
                        .collect(Collectors.joining(", "));
                logEntity.setRequestParams(params);
            }
            
            result = joinPoint.proceed();
            
            if (operationLog.recordResult() && result != null) {
                logEntity.setResultData(JSONUtil.toJsonStr(result));
            }
            
        } catch (Throwable e) {
            status = "FAIL";
            errorMsg = e.getMessage();
            log.error("操作日志记录异常：{}", e.getMessage(), e);
            throw e;
        } finally {
            long executeTime = System.currentTimeMillis() - startTime;
            logEntity.setStatus(status);
            logEntity.setErrorMsg(errorMsg);
            logEntity.setExecuteTime(executeTime);
            logEntity.setCreatedTime(LocalDateTime.now());
            
            try {
                operationLogMapper.insert(logEntity);
            } catch (Exception e) {
                log.error("保存操作日志失败：{}", e.getMessage(), e);
            }
        }
        
        return result;
    }
    
    private String getIpAddress(HttpServletRequest request) {
        String ip = request.getHeader("X-Forwarded-For");
        if (StrUtil.isBlank(ip) || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getHeader("X-Real-IP");
        }
        if (StrUtil.isBlank(ip) || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getRemoteAddr();
        }
        if (StrUtil.isNotBlank(ip) && ip.contains(",")) {
            ip = ip.split(",")[0].trim();
        }
        return ip;
    }
}
```

```java
@Service
@RequiredArgsConstructor
public class OperationLogService {
    
    private final OperationLogMapper operationLogMapper;
    
    public Page<OperationLogEntity> getLogList(OperationLogQuery query) {
        Page<OperationLogEntity> page = new Page<>(query.getPageNum(), query.getPageSize());
        
        LambdaQueryWrapper<OperationLogEntity> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(StrUtil.isNotBlank(query.getUsername()), 
                   OperationLogEntity::getUsername, query.getUsername());
        wrapper.eq(StrUtil.isNotBlank(query.getModule()), 
                   OperationLogEntity::getModule, query.getModule());
        wrapper.eq(StrUtil.isNotBlank(query.getStatus()), 
                   OperationLogEntity::getStatus, query.getStatus());
        wrapper.between(query.getStartTime() != null && query.getEndTime() != null,
                        OperationLogEntity::getCreatedTime, query.getStartTime(), query.getEndTime());
        wrapper.orderByDesc(OperationLogEntity::getCreatedTime);
        
        return operationLogMapper.selectPage(page, wrapper);
    }
}
```

### 7.2 记录数据变更前后对比
```java
@OperationLog(module = "用户管理", operation = "修改用户信息")
public void updateUser(User newUser) {
    User oldUser = userMapper.selectById(newUser.getUserId());
    
    userMapper.updateById(newUser);
    
    String diff = compareObjects(oldUser, newUser);
    log.info("用户数据变更：{}", diff);
}

private String compareObjects(Object oldObj, Object newObj) {
    Map<String, Object> changes = new HashMap<>();
    Field[] fields = oldObj.getClass().getDeclaredFields();
    for (Field field : fields) {
        field.setAccessible(true);
        Object oldValue = field.get(oldObj);
        Object newValue = field.get(newObj);
        if (!Objects.equals(oldValue, newValue)) {
            changes.put(field.getName(), oldValue + " → " + newValue);
        }
    }
    return JSONUtil.toJsonStr(changes);
}
```

## 八、注意事项

### 8.1 性能优化
1. **异步记录**：使用 `@Async` 避免阻塞主线程
2. **批量插入**：积累一定数量后批量插入数据库
3. **参数过滤**：过滤掉 `HttpServletRequest`、`SecurityUser` 等不需要记录的参数
4. **结果选择性记录**：只在需要时记录返回结果（`recordResult = true`）

### 8.2 安全注意事项
1. **敏感数据脱敏**：密码、手机号、身份证号等需要脱敏
```java
if (arg instanceof UserPasswordForm) {
    UserPasswordForm form = (UserPasswordForm) arg;
    form.setPassword("******");
}
```

2. **日志权限控制**：只有管理员可以查看日志
```java
@PreAuthorize("hasAuthority('log:view')")
public BaseResult<?> getLogList() { ... }
```

### 8.3 日志清理策略
```java
@Scheduled(cron = "0 0 2 * * ?")
public void cleanOldLogs() {
    LocalDateTime threeMonthsAgo = LocalDateTime.now().minusMonths(3);
    operationLogMapper.delete(new LambdaQueryWrapper<OperationLogEntity>()
            .lt(OperationLogEntity::getCreatedTime, threeMonthsAgo));
}
```

## 十、总结

### 10.1 核心优势
✅ **代码简洁**：一个注解完成日志记录  
✅ **业务解耦**：业务逻辑和日志记录分离  
✅ **统一管理**：日志格式、存储位置统一  
✅ **审计追溯**：记录谁、何时、做了什么、结果如何  
✅ **合规要求**：满足金融、医疗等行业的审计要求  

### 10.2 适用场景
- 用户管理：创建、修改、删除用户
- 权限管理：分配角色、修改权限
- 数据管理：修改重要配置、删除关键数据
- 财务操作：订单修改、退款操作
- 安全操作：登录、登出、密码修改

### 10.3 与Logback对比

| 场景 | 使用Logback | 使用AOP日志 |
|------|------------|------------|
| 代码执行追踪 | ✅ | ❌ |
| 异常堆栈记录 | ✅ | ❌ |
| 用户操作审计 | ❌ | ✅ |
| 数据变更追溯 | ❌ | ✅ |
| 合规审计要求 | ❌ | ✅ |

**结论**：Logback负责技术日志，AOP负责业务日志，两者配合使用。

## 十一、常见问题

### Q1：AOP日志会影响性能吗？
**A**：有轻微影响，但可以通过异步记录优化。建议只在重要操作（增删改）上使用，查询操作不建议记录。

### Q2：日志记录失败会影响业务吗？
**A**：不会。日志记录在 `finally` 块中执行，且捕获了所有异常，业务逻辑不受影响。

### Q3：如何记录数据修改前后的值？
**A**：在方法内部先查询旧数据，执行修改后对比新旧数据，记录差异。

### Q4：日志数据量太大怎么办？
**A**：
1. 定期清理旧日志（保留3-6个月）
2. 归档到历史表或文档存储
3. 使用Elasticsearch存储和查询

### Q5：如何防止敏感数据泄露？
**A**：在切面中对敏感字段（密码、手机号等）进行脱敏处理。
