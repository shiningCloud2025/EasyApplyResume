# 基于SpringBoot3+SpringSecurity+JWT实现双认证体系落地方案

## 一、项目背景与需求分析

### 1.1 项目背景
EasyApplyResume（易投简历）是一个基于 Spring Boot 3.3.5 的智能简历管理系统，包含三个端：
- **用户端**：普通用户使用，主要功能是简历制作、职位搜索等
- **管理端**：管理员使用，需要权限管理
- **广告与监控端**：运营人员使用，需要权限管理

### 1.2 核心需求
1. **双认证体系设计**
   - 用户端：独立认证体系，仅需认证（无需授权）
   - 管理端+广告监控端：共享认证授权体系，需要 RBAC 权限控制

2. **多种登录方式**
   - 账号+密码登录
   - 手机号+短信验证码登录
   - 邮箱+验证码登录

3. **安全要求**
   - 使用 JWT Token 进行无状态认证
   - 密码使用 BCrypt 加密
   - 支持 Token 主动失效（登出时从数据库/Redis删除）

4. **认证流程说明**
   - **登录阶段**：验证用户身份（查询数据库），生成JWT Token，将Token存储到Redis
   - **认证阶段**：接收请求时，解析JWT Token，**从数据库查询用户信息和权限**（不依赖Redis缓存），构建Security上下文

### 2.3 核心设计原则
1. **认证信息来源于数据库**：每次请求都从数据库查询用户信息和权限，确保数据实时性
2. **Redis 仅作Token存储**：用于验证 Token 是否有效（未被登出/失效）
3. **双层验证**：JWT 签名验证 + Redis 存在性验证，防止 Token 伪造和重放攻击
4. **职责分离**：用户端只做认证，管理端做认证+授权

### 2.4 为什么要将Token存储到Redis？

#### 问题：JWT Token 不是无状态的吗？为什么还要存储到 Redis？

**回答**：JWT Token 本身确实是**无状态**的，但在实际生产环境中，将 Token 存储到 Redis 是**安全性**与**功能性**的工程权衡。

#### 存储到 Redis 的核心原因

##### 1. **实现主动登出功能**
JWT 的无状态特性意味着：一旦 Token 签发，在过期时间前都是有效的。这带来一个问题：

```
场景：用户点击"退出登录"按钮
问题：无法让已签发的 Token 立即失效
风险：如果 Token 泄露，攻击者可以在过期前一直使用
```

通过 Redis 存储 Token 后：
```java
// 登录时：存储 Token 到 Redis
stringRedisTemplate.opsForValue().set("user:token:" + userId, token, expiration, TimeUnit.MILLISECONDS);

// 登出时：删除 Redis 中的 Token
stringRedisTemplate.delete("user:token:" + userId);

// 认证时：验证 Redis 中是否存在该 Token
String cachedToken = stringRedisTemplate.opsForValue().get("user:token:" + userId);
if (!token.equals(cachedToken)) {
    // Token 不存在或不匹配，拒绝访问
    return;
}
```

✅ **效果**：用户登出后，Token 立即失效，无法再使用。

---

##### 2. **防止 Token 伪造和重放攻击**
JWT 的签名验证只能防止 Token 被**篡改**，但无法防止 Token 被**伪造**或**重放**。

```
攻击场景：
1. 攻击者通过某种手段获取了有效的 JWT Token
2. 即使修改了密码、禁用了账号，JWT 在过期前仍然有效
3. 攻击者可以使用旧 Token 持续访问系统
```

通过 Redis 实现**双重验证**：
```
第一层验证：JWT 签名验证（防止篡改）
第二层验证：Redis 存在性验证（防止伪造和重放）
```

✅ **效果**：
- 修改密码后，删除 Redis 中的旧 Token，旧 Token 立即失效
- 禁用账号后，删除 Redis 中的 Token，该账号无法访问
- 即使攻击者伪造了签名正确的 Token，由于 Redis 中不存在，也会被拒绝

---

##### 3. **实现强制下线功能**
在管理系统中，管理员可能需要强制让某个用户下线：

```java
// 管理员操作：强制用户下线
public void forceLogout(Integer userId) {
    stringRedisTemplate.delete("user:token:" + userId);
}
```

✅ **效果**：被强制下线的用户，下一次请求时 Token 验证失败，必须重新登录。

---

##### 4. **支持单点登录（可选）**
如果需要同一账号只能在一个地方登录（防止账号共享）：

```java
// 登录时：覆盖旧 Token
stringRedisTemplate.opsForValue().set("user:token:" + userId, newToken, expiration, TimeUnit.MILLISECONDS);

// 旧 Token 自动失效，因为 Redis 中存储的是新 Token
```

✅ **效果**：用户在设备 A 登录后，之前在设备 B 的登录会话自动失效。

---

#### 可以不用 Redis 吗？

**可以，但会失去以上所有安全功能。**

| 方案 | 优点 | 缺点 |
|------|------|------|
| **纯无状态 JWT** | 完全无状态，性能更高，无需 Redis | ❌ 无法主动登出<br>❌ 无法强制下线<br>❌ Token 泄露风险大<br>❌ 修改密码后旧 Token 仍有效 |
| **JWT + Redis** | ✅ 支持主动登出<br>✅ 防止 Token 伪造<br>✅ 支持强制下线<br>✅ 支持单点登录 | 需要 Redis 依赖（轻量级状态） |

---

#### 当前方案的设计思路

本方案采用**有状态 + 无状态的混合模式**：

```
JWT 负责：携带用户基本信息（userId、username、userType）
Redis 负责：仅存储 Token 字符串，用于验证 Token 有效性（轻量级状态）
数据库负责：每次请求实时查询用户信息和权限，确保数据实时性
```

**设计权衡**：
- ✅ 保留了 JWT 的便利性（不需要每次请求都查 Redis 的用户信息）
- ✅ 增加了 Redis 的安全性（防止 Token 伪造和重放攻击）
- ✅ 用户信息和权限仍从数据库实时查询（避免缓存不一致）

这是在**安全性**、**性能**和**功能性**之间的最佳工程实践。

#### 5.2.2 JWT 工具类
**文件位置**：`security/common/JwtUtil.java`

```java
package com.zyh.easyapplyresume.security.common;

import io.jsonwebtoken.*;
import io.jsonwebtoken.security.Keys;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

@Slf4j
@Component
public class JwtUtil {
    
    public String generateToken(Integer userId, String username, String userType, String secret, long expiration) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("username", username);
        claims.put("userType", userType);
        
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + expiration);
        
        SecretKey key = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
        
        return Jwts.builder()
                .claims(claims)
                .subject(username)
                .issuedAt(now)
                .expiration(expiryDate)
                .signWith(key)
                .compact();
    }
    
    public Claims parseToken(String token, String secret) {
        try {
            SecretKey key = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
            return Jwts.parser()
                    .verifyWith(key)
                    .build()
                    .parseSignedClaims(token)
                    .getPayload();
        } catch (ExpiredJwtException e) {
            log.warn("Token 已过期: {}", token);
            throw new RuntimeException("Token 已过期");
        } catch (JwtException e) {
            log.error("Token 解析失败: {}", e.getMessage());
            throw new RuntimeException("Token 无效");
        }
    }
    
    public Integer getUserIdFromToken(String token, String secret) {
        Claims claims = parseToken(token, secret);
        return claims.get("userId", Integer.class);
    }
    
    public String getUsernameFromToken(String token, String secret) {
        Claims claims = parseToken(token, secret);
        return claims.getSubject();
    }
    
    public boolean validateToken(String token, String secret) {
        try {
            parseToken(token, secret);
            return true;
        } catch (Exception e) {
            return false;
        }
    }
}
```

### 5.3 用户端认证

#### 5.3.1 用户端 JWT 过滤器
**文件位置**：`security/user/UserJwtAuthFilter.java`

```java
package com.zyh.easyapplyresume.security.user;

import cn.hutool.core.util.StrUtil;
import com.zyh.easyapplyresume.mapper.mysql.user.UserMapper;
import com.zyh.easyapplyresume.model.pojo.user.User;
import com.zyh.easyapplyresume.security.common.JwtUtil;
import com.zyh.easyapplyresume.security.common.SecurityUser;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.Collections;

@Slf4j
@Component
@RequiredArgsConstructor
public class UserJwtAuthFilter extends OncePerRequestFilter {
    
    private final JwtUtil jwtUtil;
    private final StringRedisTemplate stringRedisTemplate;
    private final UserMapper userMapper;
    
    @Value("${jwt.user.secret}")
    private String jwtSecret;
    
    @Value("${jwt.user.token-prefix}")
    private String tokenPrefix;
    
    @Value("${jwt.user.header-name}")
    private String headerName;
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) 
            throws ServletException, IOException {
        
        String header = request.getHeader(headerName);
        
        if (StrUtil.isBlank(header) || !header.startsWith(tokenPrefix)) {
            filterChain.doFilter(request, response);
            return;
        }
        
        String token = header.replace(tokenPrefix, "");
        
        try {
            Integer userId = jwtUtil.getUserIdFromToken(token, jwtSecret);
            
            String redisKey = "user:token:" + userId;
            String cachedToken = stringRedisTemplate.opsForValue().get(redisKey);
            
            if (!token.equals(cachedToken)) {
                log.warn("Token 不匹配或已失效，userId: {}", userId);
                filterChain.doFilter(request, response);
                return;
            }
            
            User user = userMapper.selectById(userId);
            
            if (user == null || user.getUserStatus() == 0) {
```

```java
package com.zyh.easyapplyresume.security.admin;

import cn.hutool.core.util.StrUtil;
import com.zyh.easyapplyresume.mapper.mysql.admin.AdminMapper;
import com.zyh.easyapplyresume.mapper.mysql.admin.PermissionMapper;
import com.zyh.easyapplyresume.model.pojo.admin.Admin;
import com.zyh.easyapplyresume.security.common.JwtUtil;
import com.zyh.easyapplyresume.security.common.SecurityUser;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.List;
import java.util.stream.Collectors;

@Slf4j
@Component
@RequiredArgsConstructor
public class AdminJwtAuthFilter extends OncePerRequestFilter {
    
    private final JwtUtil jwtUtil;
    private final StringRedisTemplate stringRedisTemplate;
    private final AdminMapper adminMapper;
    private final PermissionMapper permissionMapper;
    
    @Value("${jwt.admin.secret}")
    private String jwtSecret;
    
    @Value("${jwt.admin.token-prefix}")
    private String tokenPrefix;
    
    @Value("${jwt.admin.header-name}")
    private String headerName;
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) 
            throws ServletException, IOException {
        
        String header = request.getHeader(headerName);
        
        if (StrUtil.isBlank(header) || !header.startsWith(tokenPrefix)) {
            filterChain.doFilter(request, response);
            return;
        }
        
        String token = header.replace(tokenPrefix, "");
        
        try {
            Integer adminId = jwtUtil.getUserIdFromToken(token, jwtSecret);
            
            String redisKey = "admin:token:" + adminId;
            String cachedToken = stringRedisTemplate.opsForValue().get(redisKey);
            
            if (!token.equals(cachedToken)) {
                log.warn("Token 不匹配或已失效，adminId: {}", adminId);
                filterChain.doFilter(request, response);
                return;
            }
            
            Admin admin = adminMapper.selectById(adminId);
            
            if (admin == null || admin.getAdminState() == 0) {
                log.warn("管理员不存在或已被禁用，adminId: {}", adminId);
                filterChain.doFilter(request, response);
                return;
            }
            
            List<String> permissions = permissionMapper.selectPermissionCodesByAdminId(adminId);
            List<SimpleGrantedAuthority> authorities = permissions.stream()
                    .map(SimpleGrantedAuthority::new)
                    .collect(Collectors.toList());
            
            SecurityUser securityUser = new SecurityUser();
            securityUser.setUserId(admin.getAdminId());
            securityUser.setUsername(admin.getAdminUsername());
            securityUser.setUserType("admin");
            securityUser.setEnabled(admin.getAdminState() == 1);
            securityUser.setAuthorities(authorities);
            
            UsernamePasswordAuthenticationToken authentication = 
                    new UsernamePasswordAuthenticationToken(securityUser, null, securityUser.getAuthorities());
            
            SecurityContextHolder.getContext().setAuthentication(authentication);
            
        } catch (Exception e) {
            log.error("管理端 Token 验证失败: {}", e.getMessage());
        }
        
        filterChain.doFilter(request, response);
    }
}
```

```java
import org.springframework.beans.factory.annotation.Value;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;

@Service
@RequiredArgsConstructor
public class UserAuthServiceImpl implements UserAuthService {
    
    private final UserMapper userMapper;
    private final PasswordEncoder passwordEncoder;
    private final JwtUtil jwtUtil;
    private final StringRedisTemplate stringRedisTemplate;
    
    @Value("${jwt.user.secret}")
    private String jwtSecret;
    
    @Value("${jwt.user.expiration}")
    private long jwtExpiration;
    
    @Override
    public UserLoginVO loginByPassword(UserLoginByPasswordForm form) {
        LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(User::getUserAccount, form.getAccount());
        User user = userMapper.selectOne(wrapper);
        
        if (user == null) {
            throw new BusException(UserCodeEnum.USER_NOT_EXIST);
        }
        
        if (!passwordEncoder.matches(form.getPassword(), user.getUserPassword())) {
            throw new BusException(UserCodeEnum.PASSWORD_ERROR);
        }
        
        String token = jwtUtil.generateToken(user.getUserId(), user.getUserUsername(), "user", jwtSecret, jwtExpiration);
        
        String redisKey = "user:token:" + user.getUserId();
        stringRedisTemplate.opsForValue().set(redisKey, token, jwtExpiration, TimeUnit.MILLISECONDS);
        
        UserLoginVO vo = new UserLoginVO();
        vo.setUserId(user.getUserId());
        vo.setUsername(user.getUserUsername());
        vo.setToken(token);
        return vo;
    }
    
    @Override
    public UserLoginVO loginByPhone(UserLoginByPhoneForm form) {
        String redisKey = "duanxin_code:" + form.getPhone();
        String cachedCode = stringRedisTemplate.opsForValue().get(redisKey);
        
        if (!form.getCode().equals(cachedCode)) {
            throw new BusException(UserCodeEnum.CODE_ERROR);
        }
        
        LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(User::getUserPhone, form.getPhone());
        User user = userMapper.selectOne(wrapper);
        
        if (user == null) {
            user = new User();
            user.setUserPhone(form.getPhone());
            user.setUserUsername("用户" + form.getPhone().substring(7));
            userMapper.insert(user);
        }
        
        String token = jwtUtil.generateToken(user.getUserId(), user.getUserUsername(), "user", jwtSecret, jwtExpiration);
        stringRedisTemplate.opsForValue().set("user:token:" + user.getUserId(), token, jwtExpiration, TimeUnit.MILLISECONDS);
        
        stringRedisTemplate.delete(redisKey);
        
        UserLoginVO vo = new UserLoginVO();
        vo.setUserId(user.getUserId());
        vo.setUsername(user.getUserUsername());
        vo.setToken(token);
        return vo;
    }
    
    @Override
    public UserLoginVO loginByEmail(UserLoginByEmailForm form) {
        String redisKey = "email_code:" + form.getEmail();

            user.setUserEmail(form.getEmail());
            user.setUserUsername("用户" + form.getEmail().split("@")[0]);
            userMapper.insert(user);

        vo.setUsername(user.getUserUsername());

        stringRedisTemplate.delete(redisKey);
```

- 认证时验证Redis Token存在性，从数据库查询用户信息和权限
- 确保权限数据实时性，避免缓存不一致问题
