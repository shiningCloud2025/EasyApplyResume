## 🐛 常见问题

### 问题1：没有思考步骤

**现象：** 
- 控制台显示：`思考步骤数量: 0`
- 页面只显示普通消息，没有折叠面板

**可能原因：**
1. 后端返回格式不包含 "步骤 X:" 标记
2. 步骤内容在同一行，没有被正确解析

**检查方法：**
```javascript
// 在控制台查看
🔍 [调试] 完整内容前500字符: ...
```

**解决方案：**
- 如果内容包含 "步骤 1:"，但步骤数量为0，说明解析正则有问题
- 将完整的返回内容复制出来，检查格式

### 问题2：没有最终结果

**现象：**
- 有思考步骤，但没有"最终结果"区域
- 显示：`⚠️ 未提取到结果（点击查看原始内容）`

**可能原因：**
1. 最后一步不包含结果标记（"结果:"、"doTerminate"等）
2. 结果提取逻辑没有匹配到内容

**检查方法：**
```javascript
// 查看最后一步的类型
🔍 [调试] 思考步骤详情: [
  { stepNumber: 1, type: 'thinking', content: '...' },
  { stepNumber: 2, type: 'result', content: '...' }  // 最后一步应该是 'result'
]
```

**解决方案：**
- 点击 "⚠️ 未提取到结果" 查看原始内容
- 检查是否有明确的结果标记

### 问题3：内容显示为JSON格式

**现象：**
- 显示大量 `{\"content\":\"...\"}`
- 引号、反斜杠到处都是

**原因：**
- 后端返回的是序列化后的JSON字符串
- 需要清理格式

**已实现的清理功能：**
- ✅ 自动移除 `\"`、`\n` 等转义字符
- ✅ 移除过长的 URL
- ✅ 清理 JSON 结构标记

**如果还是不行：**
- 检查 `formatStepContent()` 函数
- 可能需要更强的清理逻辑

### 问题4：后端返回格式异常

**现象：**
- 控制台报错
- 没有任何内容显示

**检查后端返回：**

在控制台运行：
```javascript
// 查看原始响应
📦 [AI Agent] 缓冲区内容: ...
```

**正常格式应该是：**
```
data: 步骤 1: 正在分析...

data: 步骤 2: 调用工具...

data: 步骤 3: 结果: "任务完成"
```

**如果不是这个格式，需要调整后端。**

## 🔧 调试技巧

### 技巧1：查看原始内容

点击消息下方的：
```
⚠️ 未提取到结果（点击查看原始内容）
```

可以看到完整的后端返回。

### 技巧2：手动测试解析

在控制台运行：
```javascript
// 复制后端返回的内容
const content = "步骤 1: xxx步骤 2: yyy"

// 测试正则
const regex = /步骤\s*(\d+):\s*([^步]*?)(?=步骤\s*\d+:|$)/gs
const matches = [...content.matchAll(regex)]
console.log('匹配到', matches.length, '个步骤')
matches.forEach(m => {
  console.log('步骤', m[1], ':', m[2].substring(0, 50))
})
```

### 技巧3：检查响应头

```javascript
// 查看控制台
📋 [AI Agent] 响应码: 200
📋 [AI Agent] 响应消息: Success
📋 [AI Agent] Chat ID: xxx
```

如果响应码不是 200，说明请求失败。

```typescript
const parseStepContent = (content: string) => {
  // 简化版：按"步骤"分割
  const parts = content.split(/步骤\s*\d+:/)
  if (parts.length > 1) {
    // 跳过第一个空元素
    parts.shift()
    parts.forEach((part, index) => {
      streamingSteps.value.push({
        stepNumber: index + 1,
        content: part.trim(),
        type: 'thinking'
      })
    })
  }
}
```
