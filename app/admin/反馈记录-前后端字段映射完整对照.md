## 🎯 字段使用说明

### 表格中显示的字段（7个）

| 字段 | 宽度 | 格式 | 备注 |
|------|------|------|------|
| adminFeedbackRecordAdminId | 100px | 标签 | 反馈人ID |

| adminFeedbackRecordTitle | 自适应 | 文本+溢出省略 | 标题 |
| adminFeedbackRecordOldStep | - | 标签（灰色） | 原阶段 |
| adminFeedbackRecordNewStep | - | 标签（彩色） | 新阶段 |

| adminFeedbackRecordCurrentStepSolveTime | 180px | 格式化时间 | 处理时间 |

**未在表格中显示（在详情中显示）：**
- `adminFeedbackRecordContent` - 内容（过长）

### 详情对话框中显示的字段（全部10个）

按照用户体验排列：
1. 反馈人信息（ID + 姓名）
2. 处理人信息（ID + 姓名）
3. 反馈标题（加粗突出）
4. 反馈内容（可滚动区域）
5. 状态变化（原阶段 → 新阶段）
6. 时间信息（创建时间 + 处理时间）
