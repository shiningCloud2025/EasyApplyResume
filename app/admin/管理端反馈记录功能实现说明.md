# 管理端反馈记录功能实现说明

## 📋 功能概述

**页面位置：** 反馈管理 → 管理端反馈记录

**功能：** 查看所有管理员反馈的历史处理记录

---

## 🔌 后端接口

### 1. 分页查询反馈记录

**接口：** `POST /admin/adminFeedbackRecord/findAdminFeedbackRecordPage`

**请求参数：**
- `pageNum` (可选，默认1): Integer - 页码
- `pageSize` (可选，默认10): Integer - 每页条数

**请求体：** `AdminFeedbackRecordQuery`
```typescript
{
  adminFeedbackRecordName?: string           // 反馈人姓名（模糊查询）
  adminFeedbackRecordTitle?: string          // 反馈标题（模糊查询）
  adminFeedbackRecordApprovalPersonName?: string  // 处理人姓名（模糊查询）
}
```

**响应：** `BaseResult<Page<AdminFeedbackRecordPageVO>>`
```typescript
{
  code: 200,
  message: "OK",
  data: {
    records: [
      {
        adminFeedbackRecordName: "张三",
        adminFeedbackRecordTitle: "系统功能建议",
        adminFeedbackRecordContent: "建议增加...",
        adminFeedbackRecordTime: "2024-12-15T10:00:00",
        adminFeedbackRecordCurrentStepSolveTime: "2024-12-15T15:00:00",
        adminFeedbackRecordOldStep: "待处理",
        adminFeedbackRecordNewStep: "已回复",
        adminFeedbackRecordApprovalPersonId: 1,
        adminFeedbackRecordApprovalPersonName: "超级管理员"
      }
    ],
    total: 50,
    size: 20,
    current: 1,
    pages: 3
  }
}
```

### 2. 查询反馈记录详情

**接口：** `GET /admin/adminFeedbackRecord/findAdminFeedbackRecordByFeedbackRecordId`

**请求参数：**
- `feedbackRecordId` (必填): Integer - 反馈记录ID

**响应：** `BaseResult<AdminFeedbackRecordInfoVO>`
```typescript
{
  code: 200,
  message: "OK",
  data: {
    adminFeedbackRecordName: "张三",
    adminFeedbackRecordTitle: "系统功能建议",
    adminFeedbackRecordContent: "详细内容...",
    adminFeedbackRecordTime: "2024-12-15T10:00:00",
    adminFeedbackRecordCurrentStepSolveTime: "2024-12-15T15:00:00",
    adminFeedbackRecordOldStep: "待处理",
    adminFeedbackRecordNewStep: "已回复",
    adminFeedbackRecordApprovalPersonId: 1,
    adminFeedbackRecordApprovalPersonName: "超级管理员"
  }
}
```

## 🎨 前端实现

### 1. API 定义

**文件：** `app/admin/src/api/admin.ts`

**添加的API：**
```typescript
// 反馈记录相关API
export const feedbackRecordApi = {
  // 分页查询反馈记录
  getRecordPage: (pageNum: number, pageSize: number, query: AdminFeedbackRecordQuery) =>
    api.post<PageResult<AdminFeedbackRecordPageVO>>(
      '/admin/adminFeedbackRecord/findAdminFeedbackRecordPage', 
      query, 
      { params: { pageNum, pageSize } }
    ),
  
  // 查询反馈记录详情
  getRecordDetail: (feedbackRecordId: number) =>
    api.get<AdminFeedbackRecordInfoVO>(
      '/admin/adminFeedbackRecord/findAdminFeedbackRecordByFeedbackRecordId', 
      { params: { feedbackRecordId } }
    )
}
```

### 2. 类型定义

**文件：** `app/admin/src/types/admin.ts`

**已有类型：** ✅
- `AdminFeedbackRecordQuery` - 查询条件
- `AdminFeedbackRecordPageVO` - 分页VO
- `AdminFeedbackRecordInfoVO` - 详情VO

## ⚠️ 注意事项

### 问题1：PageVO 中缺少 ID 字段

**现状：** `AdminFeedbackRecordPageVO` 没有 `feedbackRecordId` 字段

**影响：** 无法调用详情接口（需要 feedbackRecordId 参数）

**临时方案：** 直接使用 PageVO 数据展示详情（不调用详情接口）

**建议：** 后端在 `AdminFeedbackRecordPageVO` 中添加 `feedbackRecordId` 字段

### 问题2：字段名称较长

所有字段都带有 `adminFeedbackRecord` 前缀，建议后端简化命名。

**当前：**
```java
private String adminFeedbackRecordName;
private String adminFeedbackRecordTitle;
```

**建议：**
```java
private Integer feedbackRecordId;  // 添加ID
private String feedbackName;
private String feedbackTitle;
```

### 状态映射
```typescript
const getStatusType = (status: string) => {
  const map: Record<string, string> = {
    '待处理': 'warning',   // 橙色
    '待回复': 'primary',   // 蓝色
    '已回复': 'success',   // 绿色
    '已忽视': 'info',      // 灰色
    '已接受': 'success',   // 绿色
    '拒绝回复': 'danger'   // 红色
  }
  return map[status] || 'info'
}
```

### 问题1：PageVO 缺少 ID 字段

**问题：** 后端的 `AdminFeedbackRecordPageVO` 没有 `feedbackRecordId` 字段

**影响：** 无法调用详情接口

**当前方案：** 直接使用 PageVO 数据展示详情（暂不调用详情接口）

**建议后端修改：**
```java
@Data
@Schema(description = "管理员反馈记录分页信息")
public class AdminFeedbackRecordPageVO {
    @Schema(description = "反馈记录ID")  // ✅ 添加这个字段
    private Integer feedbackRecordId;
    
    // ... 其他字段
}
```

添加ID后，前端即可调用详情接口：
```typescript
const viewDetail = async (row: AdminFeedbackRecordPageVO) => {

  currentRecord.value = response.data
  detailDialogVisible.value = true
}
```
