# 管理员发邮件功能说明

## 📧 功能概述

在**管理员管理**页面，可以直接向其他管理员发送HTML格式的邮件。

## 🎯 使用流程

### 步骤1：进入管理员管理页面

**导航路径：** 网站管理 → 管理员管理

### 步骤2：找到目标管理员

在管理员列表中，找到你想发邮件的管理员。

### 步骤3：点击"发邮件"按钮

在操作列中，点击绿色的"发邮件"按钮。

**触发流程：**
```
点击"发邮件"
    ↓
调用 /admin/admin/getAdminInfo（获取当前登录用户信息）
    ↓
提取当前用户的邮箱（userEmail）
    ↓
自动填充：
  - 发件人：当前登录用户的邮箱
  - 收件人：被点击管理员的邮箱
    ↓
弹出邮件编辑对话框
```

### 步骤4：填写邮件

#### 收件人和发件人
- ✅ 自动填充，不可修改
- ✅ 发件人：通过 JWT token 从后端获取
- ✅ 收件人：从表格数据中获取

#### 邮件主题
- 纯文本输入
- 限制100个字符
- 必填项

#### 邮件内容
- **富文本编辑器**
- **HTML 格式支持**
- 必填项

### 步骤5：使用富文本工具栏

**工具栏按钮：**
```
┌─ 格式化工具 ──────────────────────┐
│ [B] [I] [U]  [H1][H2][H3]  [•][1]│
│ 粗体 斜体 下划线   标题    列表   │
│                                   │
│ [链接] [分割线]        [预览/编辑]│
└───────────────────────────────────┘
```

**快速操作：**
1. **粗体**：选中文字 → 点击 [B] → `<b>文字</b>`
2. **标题**：选中文字 → 点击 [H1] → `<h1>文字</h1>`
3. **列表**：点击 [•] → 插入列表模板
4. **链接**：点击 [链接] → 输入URL和文字
5. **预览**：点击 [预览] → 查看HTML渲染效果

### 步骤6：预览效果（可选）

点击工具栏右侧的"预览"按钮，查看邮件的最终展示效果。

### 步骤7：发送邮件

1. 点击"发送邮件"按钮
2. 确认发送对象
3. 等待发送完成
4. 看到成功提示

## 🔧 技术实现

### 前端

**文件：** `app/admin/src/views/admin/user/AdminManagement.vue`

**关键函数：**

#### 1. 获取当前用户邮箱
```typescript
const handleSendEmail = async (row: AdminPageVO) => {
  // 调用后端接口获取当前登录用户信息
  const response = await adminApi.getCurrentAdminInfo()
  const currentUserEmail = response.data.userEmail  // 从 SecurityUser 中获取
  
  // 设置发件人和收件人
  emailForm.fromEmail = currentUserEmail  // 当前用户邮箱
  emailForm.toEmail = row.adminEmail      // 目标管理员邮箱
  
  // 打开对话框
  emailDialogVisible.value = true
}
```

#### 2. 发送邮件
```typescript
const handleSendEmailSubmit = async () => {
  await emailFormRef.value.validate()
  
  // 调用后端接口发送HTML邮件
  await emailApi.sendHtmlEmailSelfDef(
    emailForm.fromEmail,   // 发件人
    emailForm.toEmail,     // 收件人
    emailForm.subject,     // 主题
    emailForm.htmlContent  // HTML内容
  )
  
  ElMessage.success('邮件发送成功')
  emailDialogVisible.value = false
}
```

### 后端接口

#### 1. 获取当前用户信息

**接口：** `POST /admin/admin/getAdminInfo`

**请求头：**
```
Admin-Authorization: Admin <JWT_TOKEN>
```

**响应：**
```json
{
  "code": 200,
  "message": "OK",
  "data": {
    "userId": 1,
    "userEmail": "admin@example.com",
    "username": "超级管理员",
    "authorities": ["ROLE_SUPER_ADMIN"]
  }
}
```

#### 2. 发送HTML邮件

**接口：** `POST /admin/email/communication/selfde/sendHtml`

**请求参数：**
- `fromEmail`：发件人邮箱
- `toEmail`：收件人邮箱
- `subject`：邮件主题
- `htmlContent`：HTML内容

**响应：**
```
无返回内容（void）
```

## 📊 数据流

```
用户点击"发邮件"
    ↓
前端调用 getCurrentAdminInfo()
    ↓
后端返回 SecurityUser（包含 userEmail）
    ↓
前端设置：
  - fromEmail = SecurityUser.userEmail
  - toEmail = 被点击管理员的 adminEmail
    ↓
弹出对话框，用户填写主题和内容
    ↓
用户点击"发送邮件"
    ↓
前端调用 sendHtmlEmailSelfDef()
    ↓
后端发送邮件
    ↓
返回成功/失败
```

## 🔒 安全机制

### 1. 身份验证
- ✅ 通过 JWT token 获取当前用户
- ✅ 确保只能以自己的名义发送
- ✅ 防止伪造发件人

### 2. 权限控制
- ✅ 需要登录才能发送
- ✅ 只能向系统内的管理员发送
- ✅ 收件人邮箱从数据库获取，无法伪造

### 3. 数据验证
- ✅ 邮件主题必填，限制长度
- ✅ 邮件内容必填
- ✅ 发送前二次确认

## 🐛 可能的问题

### 问题1：无法获取当前用户邮箱

**现象：** 提示"无法获取当前用户邮箱，请重新登录"

**原因：**
- JWT token 过期
- 后端接口返回的 SecurityUser 中 userEmail 为空

**解决：**
- 检查后端 `/admin/admin/getAdminInfo` 接口
- 确认 SecurityUser 中包含 userEmail 字段
- 重新登录获取新 token

### 问题2：邮件发送失败

**现象：** 提示"发送失败：XXX"

**原因：**
- 邮箱服务配置问题
- 收件人邮箱格式错误
- 后端服务异常

**解决：**
- 检查后端邮件服务配置
- 查看后端日志
- 确认收件人邮箱格式正确
