# AI助手消息格式化优化说明

## 🎯 优化内容

将 AI 助手的消息显示从**纯文本**优化为**富文本格式**，支持 Markdown 语法和智能格式化。

## ✨ 支持的格式

### 1. 标题（# ## ###）

**输入：**
```markdown
# 一级标题
## 二级标题
### 三级标题
```

**效果：**
- # 大标题（18px，加粗，带下划线）
- ## 中标题（16px，加粗）
- ### 小标题（14px，加粗）

---

### 2. 粗体和斜体

**输入：**
```markdown
**粗体文本** 或 __粗体文本__
*斜体文本* 或 _斜体文本_
```

**效果：**
- **粗体**（加粗显示）
- *斜体*（倾斜显示）

---

### 3. 代码

#### 行内代码

**输入：**
```markdown
使用 `Flux<String>` 返回流式数据
```

**效果：**
- 灰色背景，红色文字
- 等宽字体
- 圆角边框

#### 代码块

**输入：**
````markdown
```java
public Flux<String> chat(String message) {
    return flux;
}
```
````

**效果：**
- 深色背景（#1f2937）
- 浅色文字
- 等宽字体
- 支持语言标识

---

### 4. 列表

#### 有序列表

**输入：**
```markdown
1. 第一步
2. 第二步
3. 第三步
```

**效果：**
- 绿色数字标记
- 清晰的层级
- 适当的间距

#### 无序列表

**输入：**
```markdown
- 项目一
- 项目二
- 项目三
```

**效果：**
- 绿色圆点标记
- 统一的缩进

---

### 5. 链接

**输入：**
```markdown
访问 [百度](https://www.baidu.com) 了解更多
```

**效果：**
- 蓝色文字
- 带下划线
- 悬停变色
- 新标签页打开

---

### 6. 技术关键词高亮

**自动识别并高亮：**
- Vue3, SpringBoot, Spring Security
- JWT, RBAC, MyBatis-Plus
- MySQL, Redis, PGVector
- Docker, Nginx, OpenAPI
- Vite, Pinia, TypeScript

**效果：**
- 绿色文字（AIChat）或紫色文字（AIAgent）
- 加粗显示
- 自动识别

---

### 7. 智能分段

**自动处理：**
- 空行 → 段落分隔
- 连续文本 → 自动换行
- 保持合理间距
