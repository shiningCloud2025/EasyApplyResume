# Spring Boot 监控体系部署指南

> Actuator + Spring Boot Admin + Prometheus + Grafana 完整部署流程

---

## 一、架构概览

│  ┌──────────────┐        ┌──────────────┐                  │

**各组件职责：**
| 组件 | 端口 | 职责 |
|------|------|------|
| Actuator | - | 暴露应用指标和健康检查端点 |
| Spring Boot Admin | 9090 | 实时查看应用状态、日志、JVM |
| Prometheus | 9091 | 采集和存储时序指标数据 |
| Grafana | 3000 | 可视化仪表盘、告警配置 |

## 二、Step 1：应用端配置（Actuator + Admin Client）

### 2.1 添加 Maven 依赖

在 `pom.xml` 中添加：

```xml
<!-- Spring Boot Actuator -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>

<!-- Prometheus 指标格式支持 -->
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-registry-prometheus</artifactId>
</dependency>

<!-- Spring Boot Admin Client -->
<dependency>
    <groupId>de.codecentric</groupId>
    <artifactId>spring-boot-admin-starter-client</artifactId>
    <version>3.3.4</version>
</dependency>
```

### 2.2 应用配置

在 `application.yml` 中添加：

```yaml
spring:
  application:
    name: EasyApplyResume
  # Spring Boot Admin Server 地址
  boot:
    admin:
      client:
        url: http://localhost:9090
        instance:
          name: ${spring.application.name}
          # 多实例时确保每个实例的地址正确
          service-url: http://localhost:${server.port}

# Actuator 端点配置
management:
  endpoints:
    web:
      exposure:
        include: "*"  # 暴露所有端点（生产环境建议按需暴露）
      base-path: /actuator
  endpoint:
    health:
      show-details: always  # 显示健康检查详情
    prometheus:
      enabled: true  # 启用 Prometheus 端点
  metrics:
    tags:
      application: ${spring.application.name}  # 指标标签
```

### 2.3 验证 Actuator

启动应用后，访问以下端点验证：

- 健康检查：`http://localhost:8080/actuator/health`
- 所有端点：`http://localhost:8080/actuator`
- Prometheus 指标：`http://localhost:8080/actuator/prometheus`

## 三、Step 2：Spring Boot Admin Server

### 3.1 创建新项目

创建一个独立的 Spring Boot 项目作为 Admin Server。

**pom.xml：**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
         http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.3.5</version>
    </parent>
    
    <groupId>com.zyh</groupId>
    <artifactId>admin-server</artifactId>
    <version>1.0.0</version>
    
    <dependencies>
        <!-- Spring Boot Admin Server -->
        <dependency>
            <groupId>de.codecentric</groupId>
            <artifactId>spring-boot-admin-starter-server</artifactId>
            <version>3.3.4</version>
        </dependency>
        
        <!-- Web 支持 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>
        
        <!-- 可选：安全认证 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-security</artifactId>
        </dependency>
    </dependencies>
</project>
```

### 3.2 启动类

```java
package com.zyh.adminserver;

import de.codecentric.boot.admin.server.config.EnableAdminServer;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
@EnableAdminServer
public class AdminServerApplication {
    public static void main(String[] args) {
        SpringApplication.run(AdminServerApplication.class, args);
    }
}
```

### 3.3 配置文件

**application.yml：**

```yaml
server:
  port: 9090

spring:
  application:
    name: admin-server
  # 可选：安全认证配置
  security:
    user:
      name: admin
      password: admin123
```

### 3.4 安全配置（可选）

如果启用了 Spring Security，添加配置类：

```java
package com.zyh.adminserver.config;

import de.codecentric.boot.admin.server.config.AdminServerProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.SavedRequestAwareAuthenticationSuccessHandler;

@Configuration
public class SecurityConfig {

    private final AdminServerProperties adminServer;

    public SecurityConfig(AdminServerProperties adminServer) {
        this.adminServer = adminServer;
    }

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        SavedRequestAwareAuthenticationSuccessHandler successHandler = 
            new SavedRequestAwareAuthenticationSuccessHandler();
        successHandler.setTargetUrlParameter("redirectTo");
        successHandler.setDefaultTargetUrl(adminServer.path("/"));

        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers(adminServer.path("/assets/**")).permitAll()
                .requestMatchers(adminServer.path("/login")).permitAll()
                .requestMatchers(adminServer.path("/instances/**")).permitAll()
                .requestMatchers(adminServer.path("/actuator/**")).permitAll()
                .anyRequest().authenticated()
            )
            .formLogin(form -> form
                .loginPage(adminServer.path("/login"))
                .successHandler(successHandler)
            )
            .logout(logout -> logout
                .logoutUrl(adminServer.path("/logout"))
            )
            .csrf(csrf -> csrf.disable());

        return http.build();
    }
}
```

### 3.5 启动验证

启动 Admin Server 后访问：`http://localhost:9090`

登录后即可看到已注册的应用实例。

## 四、Step 3：Prometheus + Grafana（Docker Compose）

### 4.1 目录结构

```
monitoring/
├── docker-compose.yml
└── prometheus/
    └── prometheus.yml
```

### 4.2 docker-compose.yml

```yaml
version: '3.8'

services:
  # Prometheus - 指标采集与存储
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    ports:
      - "9091:9090"
    volumes:
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml
      - prometheus_data:/prometheus
    command:
      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.path=/prometheus'
      - '--storage.tsdb.retention.time=30d'  # 数据保留30天
      - '--web.enable-lifecycle'  # 支持热重载配置
    restart: unless-stopped
    networks:
      - monitoring

  # Grafana - 可视化仪表盘
  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    ports:
      - "3000:3000"
    volumes:
      - grafana_data:/var/lib/grafana
    environment:
      - GF_SECURITY_ADMIN_USER=admin
      - GF_SECURITY_ADMIN_PASSWORD=admin123
      - GF_USERS_ALLOW_SIGN_UP=false
      - GF_SERVER_ROOT_URL=http://localhost:3000
    depends_on:
      - prometheus
    restart: unless-stopped
    networks:
      - monitoring

volumes:
  prometheus_data:
    driver: local
  grafana_data:
    driver: local

networks:
  monitoring:
    driver: bridge
```

### 4.3 prometheus/prometheus.yml

```yaml
# 全局配置
global:
  scrape_interval: 15s      # 采集间隔
  evaluation_interval: 15s  # 规则评估间隔
  
  # 外部标签（用于告警等）
  external_labels:
    monitor: 'easyapplyresume-monitor'

# 告警规则文件（可选）
# rule_files:
#   - "alert_rules.yml"

# 采集配置
scrape_configs:
  # Prometheus 自身监控
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']

  # EasyApplyResume 应用监控
  - job_name: 'easyapplyresume'
    metrics_path: '/actuator/prometheus'
    scrape_interval: 10s
    static_configs:
      - targets:
          - 'host.docker.internal:8080'   # 实例1
          # - 'host.docker.internal:8081' # 实例2（多实例时取消注释）
          # - 'host.docker.internal:8082' # 实例3
        labels:
          application: 'EasyApplyResume'
          environment: 'dev'
```

### 4.4 启动命令

```bash
# 进入 monitoring 目录
cd monitoring

# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 重启服务（配置修改后）
docker-compose restart
```

### 4.5 验证

- Prometheus：`http://localhost:9091`
  - 点击 Status → Targets 查看采集目标状态
- Grafana：`http://localhost:3000`
  - 账号：admin / admin123

## 五、Step 4：Grafana 配置

### 5.1 添加 Prometheus 数据源

1. 登录 Grafana：`http://localhost:3000`
2. 左侧菜单 → Configuration → Data Sources
3. 点击 "Add data source"
4. 选择 "Prometheus"
5. 配置：
   - Name：`Prometheus`
   - URL：`http://prometheus:9090`（Docker 内部通信）
   - 点击 "Save & Test"

### 5.2 导入 JVM 监控仪表盘

1. 左侧菜单 → Dashboards → Import
2. 输入仪表盘 ID：`4701`（JVM Micrometer）
3. 点击 "Load"
4. 选择数据源：Prometheus
5. 点击 "Import"

**推荐仪表盘 ID：**
| ID | 名称 | 用途 |
|----|------|------|
| 4701 | JVM (Micrometer) | JVM 内存、GC、线程监控 |
| 11378 | Spring Boot Statistics | Spring Boot 应用统计 |
| 12900 | Spring Boot APM | 应用性能监控 |
| 6756 | Spring Boot 2.1 | HTTP 请求、数据源监控 |

### 5.3 配置告警（可选）

1. 进入仪表盘 → 选择面板 → Edit
2. 点击 "Alert" 标签
3. 配置告警规则，例如：
   - JVM 内存使用率 > 80%
   - HTTP 5xx 错误数 > 10
   - 响应时间 > 2s

## 六、生产环境注意事项

### 6.1 安全配置

**Actuator 端点限制：**

```yaml
management:
  endpoints:
    web:
      exposure:
        # 只暴露必要端点
        include: health,info,prometheus,metrics
  endpoint:
    health:
      show-details: when_authorized  # 需要认证才显示详情
```

**Prometheus 认证（可选）：**

可以在 Nginx 反向代理层添加 Basic Auth。

### 6.2 多实例配置

方式一：静态配置（适合实例固定）

```yaml
# prometheus.yml
- targets:
    - '192.168.1.10:8080'
    - '192.168.1.11:8080'
    - '192.168.1.12:8080'
```

方式二：服务发现（适合动态扩缩容）

```yaml
# 使用文件服务发现
- job_name: 'easyapplyresume'
  file_sd_configs:
    - files:
        - '/etc/prometheus/targets/*.json'
      refresh_interval: 30s
```

### 6.3 数据持久化

确保 Docker volumes 映射到持久化存储：

```yaml
volumes:
  - /data/prometheus:/prometheus
  - /data/grafana:/var/lib/grafana
```

### 6.4 资源限制

```yaml
services:
  prometheus:
    deploy:
      resources:
        limits:
          cpus: '1'
          memory: 2G
        reservations:
          cpus: '0.5'
          memory: 1G
```

## 七、常用操作

### 7.1 Prometheus 热重载配置

```bash
curl -X POST http://localhost:9091/-/reload
```

### 7.2 查看应用指标

```bash
# 所有指标
curl http://localhost:8080/actuator/prometheus

# JVM 内存
curl http://localhost:8080/actuator/metrics/jvm.memory.used

# HTTP 请求统计
curl http://localhost:8080/actuator/metrics/http.server.requests
```

### 7.3 常用 PromQL 查询

```promql
# JVM 堆内存使用率
jvm_memory_used_bytes{area="heap"} / jvm_memory_max_bytes{area="heap"} * 100

# HTTP 请求 QPS
rate(http_server_requests_seconds_count[1m])

# HTTP 请求平均响应时间
rate(http_server_requests_seconds_sum[1m]) / rate(http_server_requests_seconds_count[1m])

# 5xx 错误数
sum(rate(http_server_requests_seconds_count{status=~"5.."}[5m]))
```

## 九、故障排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| Prometheus 采集不到数据 | 网络不通 | 检查 `host.docker.internal` 或使用实际 IP |
| Admin 看不到应用 | 应用未注册 | 检查 `spring.boot.admin.client.url` 配置 |
| Grafana 无数据 | 数据源配置错误 | URL 用 `http://prometheus:9090` |
| 指标端点 404 | Actuator 未暴露 | 检查 `management.endpoints.web.exposure.include` |
